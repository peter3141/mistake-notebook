## 4. 失败速查（Coding Plan 报错）

| 报错 | 最可能原因 | 处理 |
| --- | --- | --- |
| `401 invalid access token` | Key 不对 / 过期 / 复制带了空格 / 用了普通 `sk-` Key | 去 Coding Plan 页重新复制 `sk-sp-` 开头的专属 Key；Vercel 改完 Redeploy |
| `403 invalid api-key` | 误用通用按量计费 Base URL（`maas.aliyuncs.com`、`compatible-mode/v1`）或 Key 与端点不配套 | `AI_BASE_URL` 只能是 `https://coding.dashscope.aliyuncs.com/v1` |
| `404` | Base URL 路径少 `/v1`，或误用了 Responses API 路径 | 本项目只走 `/chat/completions` |
| `429 / quota exceeded` | 请求太密或套餐额度用尽 | 稍后重试；设置页关掉 AI 总开关可立刻停止一切调用与费用 |
| `model 'xxx' is not supported` | 模型 ID 拼错 / 带空格 / 不是精确版本 / 大小写不对 | 用 `qwen3.7-plus`（不是 `qwen3.7`）；视觉任务用支持图片理解的模型 |
| 设置页一直显示「AI未配置」 | 环境变量没填到 Vercel、或填完没 Redeploy | 核对变量名，改完必须 Redeploy |
