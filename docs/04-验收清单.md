## A. 数据与登录

- [ ] **1. 两个不同网络/设备登录同一账号看到同一批错题**
  怎么验证：电脑连 Wi-Fi 新建「测试-跨设备同步」并插图保存 → 手机关 Wi-Fi 用 4G 打开同一网址、登录同一账号 → `/mistakes` 查看。
  通过：手机能看到这道题和图片；手机改掌握状态后电脑刷新也变。

- [ ] **2. 能新建错题、插入多张图片、编辑富文本并保存**
  怎么验证：`/mistakes/new` 填标题 → 正文加粗/列表/表格/插入公式 `$x^2$` → 连续插入 2 张图片（或拖拽/粘贴）→ 保存 → 重新打开。
  通过：内容、公式、2 张图片都还在；公式被渲染成数学符号。

- [ ] **3. 能按时间/科目/标签/错因/掌握状态筛选**
  怎么验证：在 `/mistakes` 依次切换科目、标签、错因、掌握状态、日期范围，再切「时间依据」到录入时间/复习时间，并试「按周分组」「日历视图」。
  通过：结果条数与条件一致；日历点某天能筛出当天错题。

- [ ] **4. AI整理结果先预览，确认后写入，且可回滚历史版本**（需先开启 AI）
  怎么验证：详情页点「AI整理」→ 出现预览面板（此时刷新页面，题库内容未变）→ 点「确认应用」→ 再点「保存」→ 打开「历史版本」→ 点「回滚」。
  通过：不点确认时数据库不变；确认后字段更新；回滚后能恢复旧内容。

- [ ] **5. 单题、多题、随机组卷都能打印，A4分页正常，图片不截断**
  怎么验证：列表勾选 3 题 →「打印选中」；详情页 →「单题打印」；`/review/random` 抽题 →「生成练习卷/打印」；打印对话框选「另存为 PDF」，纸张 A4。
  通过：PDF 里没有导航和按钮；每道题整体不被拆到两页；图片完整显示。

- [ ] **6. 删除进回收站并可恢复，清空回收站有二次确认**
  怎么验证：删一道题 → `/trash` → 点「恢复」；再删 → 点「清空回收站」→ 必须输入「清空」。
  通过：能恢复；不输入确认词时按钮禁用。

- [ ] **7. 移动端可正常拍照上传、编辑和查看今日待复习**
  怎么验证：手机浏览器打开网站 → 底部「拍照录题」→ 允许相机 → 拍照 → 保存 → 底部「复习」→ 看今日待复习。
  通过：相机能调起、图片被压缩上传、复习页正常显示；底部栏不遮挡内容。

- [ ] **8. Coding Plan 的 API Key 不出现在前端，Base URL 和模型配置正确**
  怎么验证：
  ① 浏览器 F12 → `Network`，随便点几次「AI整理」，看**请求头**里有没有 `Authorization: Bearer sk-sp-...`（不应有，AI 请求只从服务器发出）；
  ② F12 → `Sources` 里用正则 `sk-sp-[A-Za-z0-9]{20,}` 搜索（前端可能出现「sk-sp- 开头」这种**格式说明文字**，不算真实 Key）；
  ③ Vercel 环境变量核对 `AI_BASE_URL=https://coding.dashscope.aliyuncs.com/v1`、`AI_MODEL/VISION_MODEL/OCR_MODEL=qwen3.7-plus`；设置页看模型名；
  ④ 检查 Vercel Runtime Logs 里没有打印完整 Key。
  通过：前端请求、日志、README 都搜不到真实 Key 值；设置页显示的 Base URL 与模型正确。

- [ ] **9. OCR/图片理解使用支持视觉的 Coding Plan 模型，结果可预览确认后再保存**
  怎么验证：新建错题插一张带文字的图 → 点图片上的「识别文字」按钮 → 出现 OCR 预览区（此时正文未变）→ 点「填入题目正文」→ 保存。
  通过：识别文字进入预览区；不点填入不会自动写库；设置页显示 OCR 模型为 `qwen3.7-plus` 等视觉模型。

- [ ] **10. 统计页能看到错因分布和知识点热力图**
  怎么验证：`/stats` 切换时间范围与科目，查看错因条形图、热力图、新增趋势、复习完成率。
  通过：7 类错因都有计数；知识点格子有颜色深浅；切换筛选后数字变化。

- [ ] **11. 可生成带过期时间的只读分享链接并取消**
  怎么验证：列表页「生成只读分享」→ 用无痕窗口打开链接（不登录）→ 检查页面没有编辑按钮、看不到用户资料 → 回列表「取消分享」→ 再打开链接。
  通过：无痕可只读查看；取消后提示「该分享已被取消」。

- [ ] **12. 可导出JSON/CSV备份，并可按README步骤恢复**
  怎么验证：`/settings` 分别导出 JSON、CSV；把 JSON 内容粘回「恢复备份」→ 预览字段映射 → 确认导入。
  通过：两个文件都能下载；导入后数据追加且不覆盖原题。

- [ ] **13. 打印模板可保存和复用**
  怎么验证：`/print` 调整字段勾选 →「保存为模板」命名 → 刷新页面 → 点已存模板 → 看选项是否恢复。
  通过：刷新后模板仍在，点击即可套用。

- [ ] **14. README能让我按步骤部署成功，并包含 Coding Plan 的配置说明**
  怎么验证：按 `README.md` + `03-部署步骤.md` 从第 1 步做到第 8 步。
  通过：能拿到公网网址并登录成功；文档里有 `sk-sp-`、Base URL、模型与 401/403/404/429 排错。

## B. AI 开关与费用保护（重点）

- [ ] **16. 设置页有「启用AI功能」总开关，关闭后所有AI入口隐藏或置灰，服务端 /api/ai/* 拒绝请求，且不产生任何AI调用和费用**
  怎么验证：
  ① `/settings` 关闭总开关 → 去详情页看「AI整理」按钮置灰并显示「AI功能已关闭」，列表页「AI批量整理」消失，相似题区域显示「AI功能已关闭」，图片上的 OCR 按钮消失。
  ② 在浏览器控制台执行（**这会模拟有人绕过前端直接打接口**）：
  ```js
  fetch('/api/ai/organize',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify({title:'测试'})}).then(r=>r.json()).then(console.log)
  ```
  预期输出：`{error: "AI功能已关闭", code: "AI_DISABLED"}` 且 HTTP 403。
  ③ `/settings` 看「累计成功调用」数字前后**没有增加**。
  通过：三小项全部满足。

- [ ] **17. 支持单独控制AI整理、OCR、相似题、AI批量整理等子功能，总开关关闭时子开关全部失效**

  通过：子开关独立生效；总开关一关全部失效。

- [ ] **18. 开关状态持久化并跨设备同步，刷新、重新登录、换设备后状态一致**
  怎么验证：手机上关闭 AI → 电脑刷新 `/settings` → 退出登录再登录 → 用另一台设备登录，看开关状态。
  通过：所有场景都保持「已关闭」，设置页状态文字一致。

- [ ] **19. 未配置 DASHSCOPE_CODING_API_KEY 或 AI_BASE_URL 时，设置页提示「AI未配置」并自动禁用AI入口，非AI功能正常可用**
  怎么验证：临时在 Vercel 删掉 `DASHSCOPE_CODING_API_KEY` 并 Redeploy → 打开任意页面。
  通过：不白屏、不报错；设置页显示「AI未配置」+ 具体缺什么；新建/编辑/图片/筛选/复习/打印/统计都能用。（测完记得把变量加回来并 Redeploy。）

- [ ] **20. 关闭AI后，手动录入、编辑、图片上传、富文本、筛选、复习、随机组卷（手动）、打印、导出、回收站、备份恢复、统计页全部正常**
  怎么验证：关闭总开关后，把上面每一项各操作一遍（尤其**图片上传**和**随机组卷**）。
  通过：全部可用，且相似题/AI 建议位置显示「AI功能已关闭」而不是报错或空白。

- [ ] **21. 重新开启AI后，AI整理、OCR、相似题等功能恢复正常，不需要重新部署**
  怎么验证：在 `/settings` 重新打开总开关（**不改 Vercel、不 push 代码**）→ 立刻回详情页点「AI整理」。
  通过：返回结构化预览；OCR、相似题也恢复。

- [ ] **22. 设置页能显示「AI功能当前状态：已开启/已关闭」和当前模型名称**
  怎么验证：开关切换时看设置页顶部状态胶囊；核对下面「文本模型 / 视觉模型 / OCR 模型 / Base URL」四行。
  通过：状态文字随开关即时变化，模型名与 Vercel 环境变量一致。
